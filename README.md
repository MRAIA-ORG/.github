# .github

Org-wide defaults for MRAIA-ORG repos.

- `.github/pull_request_template.md`: the PR form for every MRAIA-ORG repo that has no template of its own. The rules behind it are in [linkja-workspace CONTRIBUTING](https://github.com/MRAIA-ORG/linkja-workspace/blob/master/CONTRIBUTING.md).
- `.github/SECURITY.md`: the security policy for every MRAIA-ORG repo that has no policy of its own. It tells a reader how to report a flaw in private and how we announce fixes. MRAIA-ORG/linkja-workspace#105.
